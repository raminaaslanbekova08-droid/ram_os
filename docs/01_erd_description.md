 Описание ER-диаграммы

 Таблицы
1.  **roles** — справочник ролей. PK: role_id. Предназначена для хранения названий ролей.
2.  **users** — пользователи системы. PK: user_id. Содержит логин, ФИО и ссылку на роль (FK: role_id).
3.  **products** — каталог товаров. PK: product_id. Содержит информацию о модели, цене, производителе.
4.  **sizes** — справочник размеров. PK: size_id. Содержит значения размеров.
5.  **stock_items** — товарные позиции. PK: stock_item_id. Связывает товар и размер, хранит количество (FK: product_id, size_id).
6.  **orders** — заказы. PK: order_id. Содержит дату и ссылку на пользователя (FK: user_id).
7.  **order_items** — состав заказа. PK: order_item_id. Содержит ссылки на заказ и товарную позицию, количество и цену на момент покупки (FK: order_id, stock_item_id).

 Связи
*   `roles` 1:N `users` — одна роль у многих пользователей.
*   `users` 1:N `orders` — один пользователь может сделать много заказов.
*   `orders` 1:N `order_items` — один заказ содержит много позиций.
*   `products` 1:N `stock_items` — один товар имеет много размеров.
*   `sizes` 1:N `stock_items` — один размер может быть у многих товаров.
*   `stock_items` 1:N `order_items` — одна позиция может входить в много заказов.
