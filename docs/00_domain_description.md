 Торговая компания «Чудо Обувь»

Торговая компания «Чудо Обувь» занимается продажей обуви и имеет сеть магазинов. Приложение для заказа обуви дает возможность клиентам компании выбирать и заказывать одну или несколько пар обуви из каталога различных моделей и размеров обуви в торговом зале. На данный момент услуга предоставляется только для обуви, в дальнейшем возможно расширение ассортимента товаров за счет аксессуаров.

 Функциональные требования:
1. В каталоге должно храниться актуальное доступное для заказа количество товарных позиций (сочетаний модели и размера).
2. Для каждой модели в каталоге должно сохраняться изображение.
3. Пользователь должен иметь возможность выбрать из каталога одну или несколько пар обуви доступного размера и модели.
4. В интерфейсе должен быть доступен просмотр списка заказов с отображением ключевой информации: дата заказа, ФИО клиента.
5. Должно быть реализовано управление заказами.

 Роли пользователей и их права:
*   **Неавторизованный пользователь:** может просматривать каталог товаров (без фильтрации, сортировки, поиска).
*   **Авторизованный пользователь:** может просматривать каталог товаров (с фильтрацией, сортировкой и поиском), оформлять заказы (добавлять/удалять товарные позиции, изменять количество).
*   **Менеджер:** может всё, что авторизованный пользователь, а также просматривать заказы, состав конкретного заказа, добавлять новые заказы и удалять существующие.
*   **Администратор:** может всё, что менеджер, а также редактировать заказы.

 Аутентификация:
Вход в систему осуществляется только по логину, указанному в списке пользователей системы. Пароль при этом вводить не требуется. Это значит, что поле `login` в таблице пользователей должно быть уникальным.

 Данные о товаре:
Для реализации фильтрации, сортировки и поиска в каталоге система должна хранить: категорию, подкатегорию, производителя, наименование, цену.
