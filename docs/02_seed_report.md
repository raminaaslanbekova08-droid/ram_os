 Отчёт о тестовых данных

Скрипт `src/db_seed.py` заполняет базу `db/shoe_store.sqlite` следующими данными:

| Таблица | Кол-во записей | Описание |
|---------|----------------|----------|
| roles | 3 | admin, manager, user |
| users | 3 | admin (Иванов), manager (Петров), user (Сидоров) |
| products | 5 | Кроссовки, Ботинки, Туфли, Сандалии, Кеды |
| sizes | 5 | 36, 37, 38, 39, 40 |
| stock_items | 10 | сочетания товаров и размеров |
| orders | 3 | заказы от трёх разных пользователей |
| order_items | 6 | 1–2 позиции в каждом заказе |

 Проверка

- Каждый заказ привязан к пользователю через `user_id`.
- Каждая позиция заказа привязана к товарной позиции через `stock_item_id`.
- Все цены положительные, количество неотрицательное.
- Логины пользователей уникальны.

 Как воспроизвести

```bash
python src/db_init.py
python src/db_seed.py
