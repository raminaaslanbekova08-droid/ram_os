 Финальная проверка схемы именования

 Правила именования (требования демоэкзамена)

1. Только латиница
2. Нижний регистр (snake_case)
3. Слова разделяются `_`
4. Начинается с буквы
5. Имена таблиц — во множественном числе
6. Имена полей — в единственном числе
7. Идентификаторы с суффиксом `_id`
8. Не использовать зарезервированные слова SQL
9. Избегать сокращений, кроме общепринятых

 Зарезервированные слова — проверка

Проверено: `order`, `select`, `from`, `where`, `index`, `table`, `column`
Ни одно из этих слов не используется как имя таблицы или поля.
Таблица заказов называется `orders` (множественное число), что допустимо.
