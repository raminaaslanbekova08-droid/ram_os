 Финальный набор ограничений целостности

 Таблица ограничений

| Таблица | Поле | Ограничение | Обоснование |
|---------|------|-------------|-------------|
| products | price | CHECK (price > 0 AND price < 1000000) | цена не может быть отрицательной, нулевой или нереально большой |
| products | name | CHECK (length(name) > 0) | наименование не может быть пустым |
| stock_items | quantity_available | CHECK (quantity_available >= 0) | количество не может быть отрицательным |
| order_items | quantity | CHECK (quantity > 0) | количество в заказе всегда больше нуля |
| order_items | price | CHECK (price > 0) | цена позиции в заказе всегда больше нуля |
| users | login | CHECK (length(login) >= 3 AND length(login) <= 20) | логин разумной длины |
| sizes | size_value | CHECK (size_value > 20 AND size_value < 50) | размеры обуви в разумном диапазоне |
| orders | order_date | CHECK (date(order_date) IS NOT NULL) | дата должна быть в формате ISO 8601 |

 Типы ограничений

 NOT NULL
Поле обязательно для заполнения. Не даёт вставить пустое значение.

 UNIQUE
Значение уникально. Не даёт создать дубликат.

 CHECK
Значение удовлетворяет условию. Не даёт вставить значение вне диапазона.

 DEFAULT
Значение по умолчанию. Подставляется, если значение не указано.

 PRIMARY KEY
Первичный ключ. Уникальный идентификатор записи.

 FOREIGN KEY
Внешний ключ. Обеспечивает ссылочную целостность.
