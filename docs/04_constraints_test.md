 Результаты проверки ограничений

Проверка выполнена с помощью скрипта `src/db_test_constraints.py`. Скрипт намеренно пытается вставить некорректные данные и фиксирует реакцию СУБД.

| Ограничение | Ожидаемый результат | Фактический результат | Статус |
| :--- | :--- | :--- | :--- |
| **UNIQUE на `login`** | Ошибка (нельзя двух юзеров с одним логином) | `UNIQUE constraint failed: users.login` | Пройден |
| **NOT NULL на `last_name`** | Ошибка (фамилия обязательна) | `NOT NULL constraint failed: users.last_name` | Пройден |
| **CHECK на `price`** | Ошибка (нельзя отрицательную цену) | `CHECK constraint failed: price > 0 AND price < 1000000` | Пройден |
| **CHECK на `quantity`** | Ошибка (нельзя отрицательное количество) | `CHECK constraint failed: quantity_available >= 0` | Пройден |
| **FOREIGN KEY на `role_id`** | Ошибка (нельзя привязать к несуществующей роли) | `FOREIGN KEY constraint failed` | Пройден |
| **ON DELETE RESTRICT** | Ошибка (нельзя удалить роль, если есть юзеры) | `FOREIGN KEY constraint failed` | Пройден |
| **ON DELETE CASCADE** | Успех (позиции заказа удаляются вместе с заказом) | Каскадное удаление сработало (позиции удалены) | Пройден |

**Вывод:** Все ограничения целостности данных работают корректно. База данных надежно защищена от нарушения логики.
