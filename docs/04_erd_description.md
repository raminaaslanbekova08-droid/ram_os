 Описание ER-диаграммы

1. **Роли и Пользователи (1:N):** Одна роль может быть назначена множеству пользователей, но у каждого пользователя только одна роль.
2. **Пользователи и Заказы (1:N):** Один пользователь может сделать множество заказов, но каждый заказ принадлежит только одному пользователю.
3. **Товары и Товарные позиции (1:N):** Одна модель обуви может иметь несколько товарных позиций (разных размеров).
4. **Размеры и Товарные позиции (1:N):** Один размер (например, 42) может встречаться у многих моделей обуви, образуя конкретные товарные позиции.
5. **Заказы и Состав заказа (1:N):** Один заказ содержит множество строк (позиций).
6. **Товарные позиции и Состав заказа (1:N):** Одна конкретная позиция (товар+размер) может входить в состав множества разных заказов.

 Проверка связей
Попытка вставить пользователя с несуществующим `role_id = 99` вызывает ошибку `FOREIGN KEY constraint failed`. Ссылочная целостность работает корректно.
