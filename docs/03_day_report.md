 Принятые решения
- **Имена:** Все имена приведены к snake_case, таблицы во множественном числе, идентификаторы с суффиксом `_id`. Исправлено имя таблицы `order` на `orders`.
- **Ограничения:** Добавлены проверки на положительную цену, неотрицательное количество, длину логина и диапазон размеров.
- **Индексы:** Созданы на все внешние ключи для ускорения JOIN, а также на поля `category`, `manufacturer` и `order_date` для ускорения фильтрации и сортировки.
- **Стратегии удаления:** Для справочников и пользователей выбрана стратегия `RESTRICT` (защита истории), для позиций заказа — `CASCADE` (удаление вместе с заказом).
