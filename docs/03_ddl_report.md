 Отчёт о финальном DDL-скрипте

 Структура скрипта `src/db_init.py`

Скрипт выполняет следующие действия:
1. Устанавливает соединение с базой данных и включает `PRAGMA foreign_keys = ON`.
2. Создаёт таблицы в правильном порядке (сначала справочники, затем зависимые таблицы):
   - `roles`
   - `users`
   - `products`
   - `sizes`
   - `stock_items`
   - `orders`
   - `order_items`
3. Добавляет ограничения `CHECK` для валидации данных.
4. Добавляет ограничения `FOREIGN KEY` с стратегиями `RESTRICT` и `CASCADE`.
5. Создаёт индексы для внешних ключей и часто используемых полей.
6. Фиксирует изменения (`COMMIT`).

Скрипт может быть запущен с нуля для создания полностью рабочей структуры базы данных.
