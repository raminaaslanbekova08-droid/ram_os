 Словарь терминов

1.  **Предметная область** — часть реального мира, которую мы автоматизируем. Пример: торговля обувью в «Чудо Обувь».
2.  **Сущность** — объект, о котором хранится информация. Пример: Товар, Заказ, Пользователь.
3.  **Атрибут** — характеристика сущности. Пример: цена товара, фамилия клиента.
4.  **Первичный ключ (PK)** — атрибут, однозначно идентифицирующий запись. Пример: `product_id`.
5.  **Внешний ключ (FK)** — ссылка на запись в другой таблице. Пример: `role_id` в таблице `users`.
6.  **Связь** — отношение между сущностями. Пример: «Один заказ содержит много товарных позиций».
7.  **Кардинальность** — тип связи. Пример: 1:N (один-ко-многим).
8.  **Нормализация** — процесс приведения структуры БД к виду, устраняющему избыточность.
9.  **Первая нормальная форма (1НФ)** — все атрибуты атомарны. Пример: размеры не хранятся списком в одной ячейке.
10. **Вторая нормальная форма (2НФ)** — все неключевые атрибуты зависят от полного первичного ключа.
11. **Третья нормальная форма (3НФ)** — отсутствие транзитивных зависимостей.
12. **Транзитивная зависимость** — зависимость неключевого атрибута от другого неключевого. Пример: название роли зависит от роли, а не от пользователя.
13. **Аномалия вставки** — невозможность добавить данные без других данных. Пример: нельзя добавить размер, не создав заказ.
14. **Аномалия обновления** — необходимость обновлять много записей при изменении одного факта. Пример: смена фамилии клиента.
15. **Аномалия удаления** — потеря данных при удалении записи. Пример: удаление заказа стирает данные о клиенте.
16. **Товарная позиция** — сочетание модели и размера. Пример: Кроссовки Nike, размер 42.
17. **Каталог** — список доступных товаров.
18. **Справочник** — таблица с фиксированным набором значений. Пример: таблица `roles`.
19. **Составной ключ** — ключ из нескольких атрибутов.
20. **Ссылочная целостность** — правило, по которому внешний ключ ссылается на существующую запись.
